# docs/append-only-ledgers.txt - the ONE list of this project's append-only ledgers.

# Read by BOTH enforcement points of validators/check-append-only.cjs: the pre-push hook
# (.githooks/pre-push, `--per-commit --ledgers docs/append-only-ledgers.txt`, every push)
# and the CI workflow (.github/workflows/append-only-ledger.yml, every pull request).
# One path per line, repo-relative, forward slashes; `#` lines and blank lines are ignored.
# A path absent from this project (a ledger it never opened) passes harmlessly: absent is
# "new", never a violation. To add or remove a ledger, edit THIS file - nowhere else.
#
# The merge valve: the walk compares each commit with its first parent, so a merge of main
# whose resolution puts main's rows above the branch's reads as a mid-file insert. Then
# resolve the branch's rows first, or add an exception (--exceptions <file>, one
# `<sha> <path> <reason>` line).
#
