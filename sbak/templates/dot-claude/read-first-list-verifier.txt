# Read-first orientation list for VERIFIER sessions.
#
# Loaded by .claude/hooks/session-start-read-first.cjs when .claude/role
# contains "verifier". DELIBERATELY OMITS prior retrospectives, milestone
# summaries, and gap-analysis carry-forward sections — those would prime the
# agent toward "we just shipped this; tests passed; it works" (the same
# confirmation bias that lets contract bugs slip through work-stage retros).
#
# To open a verifier session:
#   1. Write "verifier" to .claude/role
#   2. Open a fresh Claude Code session in this repo
#   3. The hook auto-loads this verifier-specific list
#   4. Paste the V.5 CLI Prompt from docs/build-prompts/M[NN]-*.md
#
# When the verifier session is done:
#   - Write "work" to .claude/role (or delete the file)
#   - Subsequent sessions load the standard read-first-list.txt
#
# The standard read-first-list.txt is for work-mode sessions and IS allowed
# to reference retros. This verifier list is the bias guard.
#
# Restructured under I8 (M20.5.A): ≤8 entries, top-3 orientation core, the
# protocol spine (BUILD-PLAYBOOK / STAGE-PROMPT-PROTOCOL) moved to the on-demand
# reference index the SessionStart stamp emits. The bias-guard omission (no
# prior retrospectives) is preserved.

# Entry grammar (M30.G lazy orientation): <path>  when: <boundary>  [- why]. Boundaries:
# session-start (inlined by the hook) | host (loaded by Claude Code itself) | stage-open (checked by
# approve-red) | verify (/verify step 1) | closeout (/closeout step 1) | phase-0/1/3 (bootstrap) | on-demand.
