# Read-first orientation list — auto-loaded by .claude/hooks/session-start-read-first.cjs
#
# One file path per line, relative to the repo root. Lines starting with `#`
# are comments. Blank lines are ignored. The list is capped at session start
# by the `read_first_cap` setting in project-config.md (small=4, medium=8,
# large=12, unlimited=no cap). List in priority order; the cap takes the top N
# of the entries a session reads itself - host, on-demand and phase-N entries
# sit outside it.
#
# Update this list when:
#   - A new framework-level reference becomes load-bearing
#   - A new milestone Phase doc opens (replace the previous milestone's Phase doc reference)
#   - An ADR is referenced often enough that it should auto-load
#
# The agent should not have to remember to read these — the hook handles it.
#
# Restructured under I8 (M20.5.A): ≤8 entries, top-3 orientation core
# (CLAUDE.md, project-config.md, the open Phase doc). The protocol spine
# (BUILD-PLAYBOOK / STAGE-PROMPT-PROTOCOL / PROCESS-VALIDATION /
# persistence-architecture) is NOT preloaded — it moved to the on-demand
# "reference index" the SessionStart stamp emits ("read when the stage prompt
# cites them"); the validators enforce its schema mechanically, so preloading
# it is redundant with the floor. docs/scope, docs/style, docs/design are cited
# on-demand by the stage prompt, not preloaded (they were already past the cap-8
# cut, silently — this makes the drop honest).
#
# M33.F (context assembly): the open Phase doc is read through the stage VIEW -
# `node scripts/stage-view.cjs <stage>` (/stage step 3) writes the stage section,
# its scope block, the ledger rows it names and the prior stages' decisions, with
# the HEAD hashes the gate checks; the whole Phase doc is on demand, named by a
# pattern (one match, or the entry is dead). The phase-N entries at the foot are
# the bootstrap's own reads, shown only while the bootstrap is in progress.

# Entry grammar (M30.G lazy orientation): <path>  when: <boundary>  [- why]. Boundaries:

# M33.F: `view: <stage>  when: <boundary>` names the open stage's view; a `*` in the last path
# segment resolves to exactly one file.
